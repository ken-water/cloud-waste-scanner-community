# Code of Conduct

Cloud Waste Scanner Community is a technical project for local-first cloud waste evidence and operator workflows.

Participants are expected to:

- communicate respectfully and concretely
- keep discussions focused on reproducible behavior and useful improvements
- avoid posting secrets, credentials, customer data, or unredacted scan reports
- respect the Community, Team, and Enterprise scope boundaries

Unacceptable behavior includes harassment, abuse, spam, credential solicitation, or attempts to use public project channels to disclose sensitive customer data.

Report conduct or safety concerns privately to:

- service@cloud-waste-scanner.com
