# Support

## Community support

Use GitHub Issues for:

- reproducible bugs
- skills packaging issues
- documentation fixes
- local API or export problems
- community feature requests

## Commercial or rollout support

For managed support, Team/Enterprise rollout, or commercial licensing questions, contact the maintainers through the project website or email:

- service@cloud-waste-scanner.com

## Before asking for help

Please include:

- operating system
- app/source version or commit
- whether you use connected mode or file-only mode
- relevant sanitized export or sample input
- exact command and error output when a script fails

Never post cloud credentials or unredacted customer scan reports.
