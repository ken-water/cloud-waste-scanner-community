How to operate at near-zero website cost

Replace backend work with static configuration.

1. Website

Serve `index.html`, `pricing.html`, `checkout.html`, and `download/` from static hosting. No app server required.

2. Payments

Use processor-hosted links instead of `/api/paddle/checkout-link`. Update only `js/commerce-config.js` when the links are ready.

3. Delivery

Point users to direct package assets. Those can live on GitHub Releases or public object storage instead of your own server.

4. Licensing

Use emailed license files, offline activation data, or manual fulfillment instead of a license recovery API.
