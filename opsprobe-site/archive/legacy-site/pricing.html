Simpler operations, fewer moving parts.

FAQ

How does checkout work now?

The checkout page is static. When hosted payment links are configured, it opens them directly. Until then, it falls back to a prefilled purchase email.

Do we still need a server for scanning?

No. The product remains local-first. Customers run the app on their own Windows, Linux, or macOS machines.

Can this avoid GitHub product exposure?

Yes. The purchase path no longer needs GitHub links at all. You can keep or remove the old public repository independently.
