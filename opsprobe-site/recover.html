License Recovery

Recover a license key.

Public beta access does not require a paid license. If you are using an older paid key or need help with activation, contact support with the purchase email.

What to send

  • Purchase email address, if this is an older paid key.
  • Approximate purchase date or receipt id, if available.
  • App version and operating system.
  • Operating system if you also need download help.

Where to send it

Open the feedback and support form. Do not send cloud provider credentials, secrets, private keys, or scan exports unless support explicitly asks for a sanitized artifact.
