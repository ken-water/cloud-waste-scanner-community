Pick the Right Package First

Pick the installer that matches the machine first, then verify it before you start connecting accounts.

2026-07-19 · Guide
By Ken RichUpdated 2026-08-12Reviewed for local-first cloud cost guidance

Release rules

  • Windows, Linux, and macOS packages should each have a clear file name.
  • Show a checksum next to every package.
  • Do not ask the user to guess which file they need.

What to publish

For each platform, publish the file name, a short install note, and the SHA256 hash. Keep the page concise and update only the values that changed.
