# Security Policy

Cloud Waste Scanner is local-first. The Community repository should not collect cloud credentials or send scan evidence to a hosted service.

## Report a vulnerability

Please do not open public issues for vulnerabilities.

Report security concerns through one of these channels:

- GitHub private vulnerability reporting if available on the repository
- Email: service@cloud-waste-scanner.com

Include:

- affected version or commit
- affected component
- reproduction steps
- potential impact
- whether credentials, local API tokens, exports, or scan artifacts are involved

## Sensitive data

Do not attach real cloud credentials, production account IDs, customer exports, or unredacted scan reports to public issues.

Use the sample files in `skills/examples/` for public reproduction where possible.
